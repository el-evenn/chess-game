This is a chess game built using HTML and Js.
Currently it only has the simple movement rules for each piece, alongside essential moves like castling, en passant, check/checkmate.(These are the only ones I'm familiar with at the moment since I'm a chess novice.
Later iterations will be a more inclusive version of the game.
I also tried experimenting with a lot of documentation to see how that would affect coming back to the code after a while.
